OGX-Mini Wireless

Pair, choose console, play. No phone needed for normal setup.

A Next choice   B Select choice

1. Pair a controller

Use A to highlight PAIR, then B. Put your controller in Bluetooth pairing mode. The screen changes from BT:WAIT to BT:ON when connected. Turn off older controllers if they keep reconnecting.

2. Choose your console

Choose OUTPUT, press A to cycle, then B to confirm. Go to SAVE and press B. The adapter reboots into the selected console mode.

3. Advanced configuration (optional)

Choose WEB APP only when you want to edit profiles, button mapping, or deadzones. Plug the Pico into a PC with USB and open the original OGX-Mini web app in a compatible browser.

4. Leave WebApp mode

On the OLED menu choose SAVE. It restarts in the last chosen console mode.

Xbox 360 XInput mode requires a compatible patched console. This experimental fork is based on wiredopposite's OGX-Mini. The physical menu does not replace the advanced web app.
