# QR setup page

The simple, mobile-friendly setup instructions live in index.html.

## Turn on the public URL
After merging the OLED feature into the master branch, go to:

GitHub repository > Settings > Pages > Deploy from a branch > master > /docs

The page is expected at https://nozzlenaut.github.io/OGX-Mini/ after GitHub confirms that it published. Do not print this URL until you have opened and verified it yourself.

For a very small 3D-printed QR code, use your own SHORT redirect URL which forwards to this page. That way you can edit instructions in future without reprinting the case.

The page links to the original OGX-Mini web app for advanced settings; it does not host an alternative WebUSB application.
